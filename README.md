# PyFTC

An OBS Studio automation for FIRST Tech Challenge events!

Inspired by [OBS FTC Stream Manager](https://github.com/FIRST-South-Carolina/obs-ftc-stream-manager), [obs-ftc](https://github.com/jvens/obs-ftc), and [RoboClipper](https://github.com/timtim17/roboclipper-ftc-web).

## Features
- Scene switching based on field number, triggered by FTCLive events.
- Saving of match recordings using OBS's replay buffer.
